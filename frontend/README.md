# ComplaintGuard frontend

This directory contains the Day 2 Next.js foundation for ComplaintGuard. It uses TypeScript, the App Router, Tailwind CSS, ESLint, a `src` directory, and npm.

No ComplaintGuard workflows, Firebase integration, translation, charts, state management, or UI-component packages are included yet.

## Verified commands

From this directory on Windows PowerShell:

```powershell
npm.cmd install
npm.cmd run dev
npm.cmd run lint
npm.cmd run build
```

Open `http://localhost:3000` after starting the development server. Use `npm.cmd` if PowerShell blocks the `npm.ps1` launcher.
